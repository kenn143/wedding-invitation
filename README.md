# Wedding Invitation (React + Vite)

## Run it
```bash
npm install
npm run dev      # open the local URL it prints
npm run build    # production files go to /dist
```

## Make it yours
- Names, date, venues and text: `src/weddingData.js`
- Colors, fonts and animations: `src/index.css` (colors are the CSS variables at the top)
- RSVP storage: see the comment in `src/Rsvp.jsx`

Deploy the `dist` folder to Netlify, Vercel, GitHub Pages or any static host.
